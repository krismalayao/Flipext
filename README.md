# Flipext: Text Converter

Imagine copying text across multiple tabs, only to manually fix ALL-CAPS headlines, re-capitalize sentences, or title-case product names word by word. Flipext is an extension that makes text case formatting effortless. With instant one-click copying and pasting, text transformation is fast, seamless, and completely accessible right inside your browser sidebar.

## 📋 Features

- **One-Click Clipboard Actions:** Instantly paste and copy text directly with dedicated action buttons.
- **Multiple Case Transformations:** Convert your text to UPPERCASE, lowercase, Sentence case, or capitalize the First Letter of every word instantly.
- **Auto-Formatting on Paste:** Automatically transforms pasted text based on your currently selected casing option.
- **100% Offline & Private:** Runs entirely inside your browser—zero data collection, external servers, or network calls required.

## ⚙️ Installation

1. Download the [FlipextExtension.zip](https://github.com/krismalayao/Flipext/blob/Flipext/FlipextExtension.zip) from this repository to your local machine.
2. Open Chrome and navigate to [chrome://extensions/](chrome://extensions/).
3. Enable Developer mode using the toggle switch in the top-right corner.
4. Click Load unpacked in the top-left corner.
5. Select the folder containing the files.
6. Open the Chrome Side Panel or click the extension icon to start managing your tabs.
